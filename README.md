# Travel Booking Website - Istanbul

This project is a two-page travel reservation website for Istanbul, built using semantic HTML5 and custom CSS3 as part of the Orange Coding Academy coursework.

## Project Structure
* `index.html`: Main travel guide featuring destination details, pricing tables, trip itineraries, and embedded media elements.
* `booking.html`: Interactive reservation form using advanced HTML5 form controls, data validation, file uploads, and selection elements.
* `style.css`: Shared stylesheet providing standard layout styling, form visual hierarchy, and table formatting.

## Features & Implementation
* Semantic HTML structure (`header`, `nav`, `main`, `article`, `section`, `footer`).
* SEO baseline setup and JSON-LD structured metadata.
* Responsive table layout with `colspan` and `rowspan` attributes.
* Form accessibility with explicit labels, input constraints, and grouped fields (`fieldset`/`legend`).
